1

Know the controller

The controller has 2 sticks and 8 buttons. Each one has a name. Your program uses these names.

Try it: press W A S D, the arrow keys, or 1 to 8. The picture lights up the same way the simulator reads your keys.

Axis A0
Axis B0
Axis C0
Axis D0

Stick numbers

Each stick gives a number from -100 to 100.

Left stick (axis A)Number
Push it all the way up100
Let go (middle)0
Pull it all the way down-100

Axis B and axis C are left and right. Right is 100. Left is -100.

2

Add a Controller to your robot

You must do this first. Without it, the controller blocks do not show up.

  1. Open the simulator.
  2. Click Devices.
  3. Click + Add a device.
  4. Click Controller. If you see a Done button, click it.
  5. A controller picture shows up next to the field. Now you can use it.

You program the controller with blocks. Pick a way to start:

3. Button blocksDo something when you press a button. 4. If thenCheck a button again and again. 5. One stickUse the stick number as the speed. 6. Tank driveDrive and turn with both sticks.
3

Button blocks

A button block runs when you press a button. Use 2 blocks: one for pressed and one for released.

when Controller button E Up pressed drive forward
when Controller button E Up released stop driving
  1. Find the blocks in Events, under Controller.
  2. Drag out when Controller button E Up pressed.
  3. Snap drive forward under it.
  4. Drag out a second button block. Change pressed to released.
  5. Snap stop driving under it.
  6. Click Start. Hold E Up. Let go.
Why 2 blocks? The first block starts the robot. Without the released block, the robot never stops.

Make E Down drive reverse the same way.

4

If then, in a forever loop

The forever loop asks again and again: "Is the button pressed?" If yes, the motor spins. If no, the motor stops.

when started forever
if Controller F Up pressed? then
spin Motor4 forward
else
stop Motor4
  1. Start with when started.
  2. Add forever from Control.
  3. Put if then else inside forever.
  4. From Sensing, drag Controller F Up pressed? into the if space.
  5. Put spin Motor4 forward under then.
  6. Put stop Motor4 under else.

Use your own motor name instead of Motor4. You can only pick a motor you added in Devices.

Two buttons? Put a second if then else inside the first else. Check F Down there and spin the motor reverse. The last else stops the motor.
5

One stick drives

The stick number can be the robot's speed. Push up a little to go slow. Push up all the way to go fast. Pull down to go backward.

when started forever
set drive velocity to Controller axis A position % drive forward
  1. Start with when started and forever.
  2. Put set drive velocity to 50 % inside forever.
  3. From Sensing, drag Controller axis A position on top of the 50.
  4. Put drive forward under it.
  5. Click Start. Push the left stick up and down.

This drives forward and backward only. To turn too, use tank drive (part 6).

6

Tank drive (both sticks)

Tank drive: the left stick drives the left wheel. The right stick drives the right wheel. Push both up to go forward. Push one up and one down to spin.

For this you need 2 motors, not a Drivetrain. Each wheel gets its own motor.

Set up first

  1. In Devices, click the Drivetrain. Click Delete device.
  2. Add a Motor on port 1. It is called Motor1. This is the left wheel.
  3. Add a Motor on port 6. It is called Motor6. This is the right wheel. Check Reverse direction.
when started forever
set Motor1 velocity to Controller axis A position % spin Motor1 forward set Motor6 velocity to Controller axis D position % spin Motor6 forward
  1. Start with when started and forever.
  2. Put set Motor1 velocity to 50 % inside forever.
  3. Drag Controller axis A position on top of the 50.
  4. Add spin Motor1 forward.
  5. Do the same for Motor6, but use axis D.
  6. Click Start. Push both sticks up.
Robot spins when both sticks are up? Open Motor6 in Devices and check Reverse direction.

Want buttons too? Add button blocks (part 3) for your arm or claw motor.

7

Test your program

You can test with any of these. Pick the one you have.

On the screen

  • Drag the sticks on the controller picture. Click the buttons.

With the keyboard

  • W and S = left stick up and down (axis A).
  • A and D = left stick left and right (axis B).
  • ↑ and ↓ = right stick up and down (axis D).
  • ← and → = right stick left and right (axis C).
  • 1 E Up, 2 E Down, 3 F Up, 4 F Down, 5 L Up, 6 L Down, 7 R Up, 8 R Down.

Click on the field first, so the keys go to the simulator.

With a real controller

  • VEX IQ (2nd gen) controller: turn it on. Plug it into the computer with USB. Click Connect real controller. Pick the VEX port.
  • VEX V5 controller: leave it turned off. Plug it in with USB. Press any button.
  • Other controllers: ask Mr. Brown.
It worked if the light next to the controller picture is green.
8

Fix it

Click a problem to see what to try.

I can't find the controller blocks.

Add a Controller in Devices first (part 2). The blocks show up after that.

Nothing happens when I press a button.
  • Did you click Start? The program must be running.
  • Check the button name in your block. Is it the same button you are pressing?
  • Using the keyboard? Click on the field first.
The robot never stops.

Add a released block with stop driving (part 3). Or use if then else with a stop under else (part 4).

The robot jumps or shakes.

Check that only one part of your program drives the wheels. Two stacks that both drive the robot will fight.

The motor I want is not in the list.

Add the motor in Devices first. Then pick it in your block.

The real controller light stays yellow.

Read the words next to the light. Do what they say. If it still doesn't work, ask Mr. Brown.
