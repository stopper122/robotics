VEX IQ Controller Test

This page checks whether the computer can read the VEX IQ controller's sticks and buttons over USB. It records what the controller sends while you move each stick and press each button. You then copy the log and send it to Claude, who works out how to use it in the Robot Field Simulator.

1. Connect

  1. Use Chrome or Edge on a computer (not a phone).
  2. Plug the IQ controller into the computer with its USB cable and turn it on. If it is paired with a Brain, turn the Brain on too.
  3. Close VEXcode and any other tab that is connected to the controller, so this page can use it.
  4. Click each button below. A box will pop up: pick the VEX device and click Connect. If more than one VEX item is listed, connect one, then click the button again for the next one.

A regular game controller is also checked automatically. If the IQ controller shows up there, press any button on it once so the browser notices it.

2. Record each move

Press Start recording, then do what the box says and keep holding it until the box changes (about 3 seconds each). Let go between steps.
